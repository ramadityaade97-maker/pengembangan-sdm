**Tanggal:** 2026-09-28

**Ruang lingkup:** 9 Blade view, 10 file CSS, 2 file JS, `routes/web.php`, config env

## Ringkasan

Project ini sebenarnya **dua design system yang tidak pernah disatukan**:

| Grup | Halaman | CSS | Tailwind |
|---|---|---|---|
| A (modern) | welcome, sop, interview, diklat | `public/css/app.css` (2663 baris) | CDN |
| B (legacy) | training, tailor, lokakarya, karier dosen, sdm | 5 file sendiri (189 baris masing-masing) | tidak ada |

Grup B adalah 5 file CSS yang **99% duplikat**. Grup A modern, tapi sarat pola AI.

Yang **sudah benar dan harus dipertahankan**: kontras warna (lolos WCAG AA, sudah diverifikasi dengan perhitungan), `prefers-reduced-motion`, dan 9 route yang semuanya berfungsi.

## HIGH — Hard Gate

### 1. Navigasi mati: 10 link `href=""` (R-24, R-26)
`training`, `tailor`, `lokakarya`, `karier dosen`, `sdm` — masing-masing baris 18-19:
```html
<a href="">Tentang</a>
<a href="">Program</a>
```
Klik -> reload halaman yang sama. 10 tautan janji yang tidak pernah ke mana.

### 2. Footer "Navigasi" bukan link (R-24, R-26)
Di 5 halaman legacy, daftar footer `Beranda / Tentang / Program / Program Kami` ditulis sebagai `<p>`, bukan `<a>`. Terlihat seperti navigasi, tapi tidak bisa diklik.

### 3. Ikon sosial adalah `<img>` telanjang (R-26)
`facebook.svg`, `twitter.svg`, `instagram.svg`, `linkledin.svg`, `youtube.svg` — 5 ikon × 5 halaman legacy, tanpa pembungkus `<a>`. Terlihat seperti tombol, bukan link.

### 4. Fokus keyboard hampir tidak ada (R-32)
Seluruh project punya **tepat 1** rule fokus:
```
welcome.blade.php:267  #program .program-card:focus-visible { outline: 2px solid #2563EB; }
```
8 dari 9 halaman tanpa style fokus sama sekali. Pengguna keyboard tidak tahu posisi kursor.

### 5. Modal galeri tidak aksesibel (R-32)
`galleryModal` muncul 18x, punya handler Escape, tapi `aria-modal` / `role="dialog"` = **0**. Pembaca layar tidak tahu ada dialog.

### 6. HTML rusak: `</div class="bawah">` (bug nyata)
5 halaman legacy, tag penutup salah:
```
training.blade.php:101, tailor.blade.php:86, sdm.blade.php:91,
lokakarya.blade.php:108, karier dosen.blade.php:133
```
`<div>` tidak bisa punya atribut class di tag penutup. Browser memproksinya, tapi struktur DOM jadi tidak sesuai maksud.

### 7. Tidak ada responsive di 8 dari 9 halaman (R-03)
Hanya `app.css` (6 breakpoint) dan `welcome.blade.php` (2) punya `@media`. Audit ini menunjukkan:
```
training.css  @media x0      tailor.css   @media x0
lokakarya.css @media x0      diklatsdm.css @media x0
karier.css   @media x0      interview.css @media x0
sop.css      @media x0      diklat.css   @media x0
```
Dikombinasikan dengan nilai fixed yang besar di CSS legacy:
- `.gambar img { width: 550px }` — meluber di layar 375px
- `.sub-judul { width: 540px }`
- `.judul { padding-left: 120px; gap: 100px }`
- `.foto img { width: 450px }`
- `.hero { height: 600px }`
- `.section-1/2/3 { min-height: 100vh }` (termasuk chrome browser di mobile)

## MEDIUM — Purpose-Gate

### 8. Delapan file CSS, satu baris berbeda (R-14, C-3)
`training / tailor / lokakarya / karier / diklatsdm / interview / diklat / sop` - masing-masing 189 baris. Perbandingan menunjukkan **hanya 13 baris yang berbeda total**, semuanya satu properti:
```css
background-image: url('/images/hero 7.png');   /* satu-satunya perbedaan */
```
Duplikasi: **932 dari 945 baris (~99%)**.

### 9. Tiga file CSS orphan
`public/css/diklat.css`, `interview.css`, `sop.css` - ketiga halaman tersebut sudah pindah ke `css/app.css`, jadi 3 file ini (464 baris) tidak direferensikan view manapun.

### 10. `resources/views/ade.php` — 2990 baris, tidak pernah dipakai
Tidak di-route, tidak di-link dari view mana pun.

### 11. `public/app.css` (root) — 121 baris, orphan
Semua view memakai `asset('css/app.css')` (folder), bukan file root.

### 12. Mismatch class: `tajuk-atas` vs `.judul-atas` (dead CSS)
HTML (5 halaman): `class="tajuk-atas"`
CSS (semua 9 file): `.judul-atas { margin-bottom: -40px; color: #006BFF }`
Aturan itu **tidak pernah aktif**. Warna aksen yang dimaksud hilang.

### 13. `public/js/app.js` — 80 dari 148 baris mati
Blok "Gallery Slider" (baris 1-81) mencari `.gallery-wrapper` / `#galleryContainer`:
```
galleryWrapper   di welcome: 0 kemunculan
galleryContainer di welcome: 0 kemunculan
```
Halaman sudah pakai galeri baru (`galleryTrack` / `galleryPrevBtn`). Blok lama langsung `return`. 54% file adalah dead code.

### 14. Radial orbs + glow float tanpa tujuan (R-01, R-13, R-19) — `diklat.blade.php`
```html
<div class="absolute -top-40 -left-40 w-[720px] h-[720px] rounded-full opacity-25"
     style="background:radial-gradient(circle at 30% 30%, #3b82f6 0%, transparent 60%);
            filter:blur(40px); animation:glowFloat 8s ease-in-out infinite;"></div>
```
2 orb blur 40px dengan animasi loop tak berujung, plus `radial-gradient` background 600px, plus 19 gradient total di satu halaman. `diklat` adalah halaman paling slop di project.

### 15. Background grid (R-07) — `diklat.blade.php:34`

                 linear-gradient(90deg, rgba(255,255,255,0.12) 1px, transparent 1px);

### 16. Badge kapsul + titik berdenyut (R-09, R-13) - `diklat.blade.php:40-41`

Kombinasi lengkap yang paling mencolok: pill + border tipis + backdrop-blur + uppercase tracking + titik hijau **berglow**. Dan label itu mengulang kata "Diklat" yang sudah ada di H1.

### 17. Eyebrow uppercase tracking lebar (R-06)

## LOW — Quality Locks

### 21. Em dash di 24 tempat (R-02)
Terdapat di `diklat` (14), `interview` (5), `sop` (3), dan muncul di `<title>` yang terlihat di tab browser.

### 22. `<title>Document</title>` di 5 halaman
Judul tidak pernah diisi. Ini juga menampilkan kata "Document" di tab browser dan di hasil pencarian.

### 23. 5 halaman tanpa `<h1>` (R-25 / SEO)
`training`, `tailor`, `lokakarya`, `karier dosen`, `sdm` — mulai langsung dari `<h2>`. `welcome` punya h1 tapi 21 h3 tanpa h2 di badan halaman.

### 24. `lang="en"` di halaman berbahasa Indonesia
`training`, `tailor`, `lokakarya`, `karier dosen`, `sdm`, dan `welcome`. Hanya `diklat`/`interview`/`sop` yang benar (`lang="id"`).

### 25. Duplikasi selector di `app.css`
21 selector muncul lebih dari sekali, `.gallery-item` 5×, `.gallery-title` 4×.

### 26. `z-index` dobel di `nav` (semua CSS legacy)
```css
nav { z-index: 1; ... z-index: 1000; }
```
Yang kedua menimpa yang pertama. Bekas copy-paste.

### 27. Negative margin untuk kompensasi layout (C-4 fragility)
`margin-bottom: -40px` (`.judul-atas`), `margin-bottom: -10px`, `margin-top: -20px`. Layout dipegang oleh nilai negatif, rapuh saat font gagal load.

### 28. `<br>` dipakai sebagai alat layout
Halaman legacy memecah paragraf dengan `<br>` di dalam teks (bisa 5-6 berturut). Membuat konten sulit dibaca dan merusak zoom 200% (WCAG 1.4.4).

### 29. Route dengan spasi (Laravel hygiene)
```php
Route::get('/karier dosen', function () { return view('karier dosen'); });
```
Butuh `%20` di URL, buruk untuk berbagi dan SEO. Nama file view juga ada spasinya.

### 30. `.env` masih default Laravel
```
APP_NAME=Laravel          APP_URL=http://localhost
APP_LOCALE=en             APP_FALLBACK_LOCALE=en
```
`APP_LOCALE=en` padahal semua konten Indonesia (`id`).

### 31. Tailwind CDN tanpa lockfile
`cdn.tailwindcss.com` di 4 halaman. Ini compiler runtime di production, lambat, dan tidak konsisten antar halaman. `public/build/manifest.json` sudah ada tapi tidak ada view yang memakai `@vite`.

## Rencana Perbaikan (3 Fase)

**Fase 1 — Fungsional & aksesibilitas (Hard Gate)**
1. #1, #2, #3 - Beri nav/footer/social tujuan yang nyata. Kalau `Tentang`/`Program` memang belum jadi halaman, hapus dari nav (R-24 lebih baik daripada link mati).
2. #6 — Perbaiki 5× `</div class="bawah">` jadi `</div>`.
3. #4 — Tambahkan `:focus-visible` global di `app.css` (satu rule, berlaku ke 9 halaman).
4. #5 — Tambahkan `role="dialog"` + `aria-modal="true"` + focus trap ke `galleryModal`.
5. #7 — Tambahkan breakpoint mobile ke 5 halaman legacy. Ini pekerjaan terbesar di fase ini.

**Fase 2 — Duplikasi & dead code**
6. #8 - Gabung 5 CSS legacy jadi 1 file, pakai variabel `--hero-image` per halaman. Hemat ~750 baris.
7. #9, #10, #11 — Hapus 3 CSS orphan, `ade.php`, `public/app.css`.
8. #12 — Samakan `tajuk-atas` → `judul-atas` (atau ganti CSS ke `tajuk-atas`).
9. #13 — Hapus blok gallery slider dari `app.js`.

**Fase 3 — Polish visual & copy (opsional, perlu persetujuan)**
10. #14, #15, #16, #17, #18, #19 — Kurangi orb/glow/grid/badge/eyebrow di `diklat` & `welcome`.
11. #20 — Alt text deskriptif.
12. #21, #22, #23, #24 — Em dash, title, heading, lang.
13. #29, #30 — Route tanpa spasi, `.env` diisi sesuai project.
14. #31 — Ganti Tailwind CDN dengan build Vite yang sudah ada di `public/build`.

> Item 10 di Fase 3 mengubah **penampilan**, jadi perlu keputusan: apakah brand lembaga riset ini memang ingin nuansa "premium tech" yang gelap, atau mau dibuat lebih tenang seperti halaman legacy? Itu keputusan desain, bukan keputusan teknis.
